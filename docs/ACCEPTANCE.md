# 当前验收状态（v0.4.0 / schema 0006）

## 已实现

| 范围 | 实现与证据 |
|---|---|
| 节点与通道 | 独立 HTTP/HTTPS/SOCKS5 绑定、禁止直连、被动状态、冷却和原节点恢复；本地隧道测试 |
| 会话 | 加密、自动续取和退避；网页登录挑战仍需人工登录 |
| 席位 | 手填总席位，完整分页占用、去重、预留；发送前重新核验；旧快照不永久拦截邮箱 |
| 兑换 | 通用 CDK 按名称/本地 ID 选择空间，串行邀请、原收据、明确失败后管理员补发 |
| 异常处理 | 待核实请求禁止自动重放；只读核实已邀请；管理员确认未发送后释放预留 |
| 队列 | 排队位置、取消未开始任务、重启恢复未开始邀请/重发任务 |
| 管理界面 | 精简分区；进入列表自动加载，任务状态自动更新，操作结束同步相关列表与席位 |
| 自动维护 | 调度心跳、异常重试、管理员维护状态及会话/节点告警；健康检查报告停滞 |
| 备份 | 定时在线快照、完整性检查、自动备份轮换、失败退避及界面告警；隔离恢复测试 |
| 部署 | Docker 单进程、安装/更新/备份脚本、HTTPS 示例；远程 CI 及服务器验收仍未执行 |

## 明确限制与待验收

- 本轮用户选择跳过真实邀请。实际邮件送达、接受邀请与普通测试成员移除尚未完整验收。
- 本地真实成员和邀请读取有过成功验证；自动续取曾返回 web_verification，需网页验证，不能承诺永久无人值守。
- 网页模式撤销邀请、指定席位仍未开放；总席位由管理员填写。
- 不支持多个实例或多个应用进程；串行不能阻止其他系统或官方管理台同时修改数据。
- 成员到期提醒、自动清退、多管理员角色、异地备份及外部通知未实现。
- 没有目标 GitHub 仓库或服务器，本轮不推送、不发布、不执行远程部署。

测试清单与运行方法见 TESTING.md；新接口见 API.md；部署配置与回退见 DEPLOYMENT.md。
