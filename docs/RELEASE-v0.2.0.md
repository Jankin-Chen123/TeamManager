# v0.2.0

## 新功能

- 节点被动健康观测、冷却熔断、原节点恢复检查；所有空间流量强制经绑定代理。
- 网页 accessToken 临期自动续取、Cookie 更新、失败退避与状态提示。
- 单次 CDK 批量生成、下载、兑换截止时间、绑定空间和邮箱、停用。
- 公开 /join 兑换页，持久化邀请任务与收据查询，一码一次、重复不重发。
- 未开始的兑换任务在重启后继续；在途写请求结果不明保留待核实。
- Linux Docker-only 首次安装脚本与更新脚本、反向代理示例。

## 升级

先备份数据库与匹配的主密钥，启动时自动升级至 Alembic 0005。已有空间默认开启自动续取，仅网页模式且具备有效登录 Cookie 时可完成续取。节点最初为 unknown，从后续请求积累状态。

## 边界

- 网站登录会话和验证策略不由本项目控制。Cookie 失效或出现 web_verification 时需重新登录；不能保证永久免人工登录。
- 不猜测网页撤销邀请接口；本版仍禁用网页登录模式的邀请撤销和席位指定。
- CDK 截止时间不是成员使用期限，本版不自动清退。
- 单实例单进程 SQLite；源码提供 CI/GHCR 发布流程，不代表已在远程仓库或服务器发布。
- 前台历史列表仍只在手动刷新时更新缓存。
