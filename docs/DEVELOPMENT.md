# 开发计划与实现边界

## 目标

管理多个 ChatGPT 工作空间，每个空间独立绑定 HTTP / SOCKS5 出口和网页登录会话（或可选 Admin key）。本机运行验证后，通过 Docker 与 GitHub Actions 发布、更新。

## 当前实现

- FastAPI 后端，Vue 3 + TypeScript 前端。
- SQLite、SQLAlchemy，Alembic `0001` 初始迁移、`0002` 查询索引、`0003` 运行设置与可追溯记录、`0004` 网页会话凭据、`0005` 自动维护/CDK；启动时迁移。
- 单管理员登录、密码修改、数据库会话、CSRF、防止明文密码日志回传。
- 节点配置、加密认证、启停、出口测试、引用删除保护。
- 空间配置、密钥更新、节点绑定、启停、按分钟探测。
- 节点 / 成员读取 / 邀请读取分层探测；保留逐项结果。
- 成员和邀请分页、已加载记录筛选、单项详情。
- 单个或批量邀请、撤销 / 重发邀请、移除普通手动管理成员。
- 持久化批量任务和逐项结果；中断写操作标记待核实，未开始项停止。
- 全局并发限制和空间级串行锁；定时只读探测。
- 操作记录保存节点、空间名称快照、错误分类、任务编号和上游请求标识；不存密钥明文。
- 节点最近测试与测试历史、绑定空间名称；探测任务与逐项结果持久化。
- 在线调整超时、全局并发、记录保留天数；清理保留待核实任务。
- 概览显示空间状态分布、最近异常任务；空间详情可查询本空间日志。
- 本机启动脚本、备份工具、Docker、Compose、GitHub Actions、服务器更新脚本。

## 更新设计

- 更新镜像，不替换数据库。
- 主密钥独立于数据库保留，主密钥丢失无法恢复加密凭据。
- 更新前停止服务，备份数据库与部署配置，启动新版本时迁移。
- 后续迁移必须创建新 revision，不改写已发布的迁移文件。
- 第一版只支持单实例单进程。不得运行多个 Uvicorn workers 或多个服务副本。

## 暂缓功能

- 自动清退到期成员、自动切换代理、节点负载均衡。
- 多管理员和细粒度权限、PostgreSQL、多进程任务队列。
- 用量、席位调整、账务、续费自动化。
- 图像识别和页面点击式成员管理（现使用网页直接 HTTP 请求）。
- 待核实任务自动对账：目前提供逐项结果及前往空间查询入口，不自动重放写请求。

## 网页协议适配

参考 Team-Workflow 的固定网页路径，独立实现 curl_cffi 适配器，保留 TLS 校验和代理强绑定。兼容旧 Admin API 数据，不自动转换凭据。Cookie 刷新只由用户手动触发。网页撤销邀请缺少已验证契约，明确禁用；不引入参考项目的注册或轮换流程。

## 列表更新规则

前端的空间成员、邀请、探测记录、空间/全局操作记录与任务列表使用浏览器持久缓存。页面和标签导航仅读取缓存；数据 HTTP 请求仅由对应刷新按钮（含刷新下一页/更早记录）触发。刷新成功保存数据、分页状态和时间，失败不覆盖旧缓存。详情从缓存记录展示，不额外读取上游。去掉自动轮询和操作后自动刷新列表。空间配置、显式探测/邀请等独立操作保留原有功能；这些操作完成不自动更新缓存列表。缓存不跨浏览器共享。

## v0.2.0 自动管理

新增 Automation：被动节点观测、熔断冷却、原节点恢复检查、会话临期续取及退避。网关统一执行维护检查，空间/节点锁和全局限制器协调后台任务与人工请求。前台缓存不由后台任务自动覆盖。

新增单次 CDK、公开兑换与收据查询。创建兑换、Job 和 JobItem 共用一个事务；Job 由 queued 条件更新独占领取。启动时仅恢复兑换关联且未开始的 queued 任务，其余按原来的失败/待核实规则处理。保留所有关联兑换任务，避免日志清理后丢失幂等结果。
